# KORGAN

**Görüntü işleme tabanlı hedef tespit sistemi için masaüstü kontrol arayüzü.**

Kamera görüntüsünü gerçek zamanlı işler ve sistemi manuel veya otonom modlarda yönetmeyi sağlar.

## Neler yapar

- Gerçek zamanlı kamera görüntüsü ve hedef tespiti
- Manuel ve otonom çalışma modları
- Ayarlanabilir kontrol paneli

## Teknolojiler

C# · WPF · .NET · Görüntü işleme
